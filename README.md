# Бюджет 2026 — семейный трекер

Приложение Полины и Оксаны: долги, планы трат и копилка на пути к 7 млн.
Открывается по ссылке, ставится на домашний экран телефона как обычное приложение.

**Живая версия:** https://polygely97.github.io/budget-tracker/

## Что умеет

- 💸 Расходы по категориям — с выбором счёта, датой и заметкой
- 💰 Доходы
- 🔄 Переводы между счетами (₽ ↔ ฿ ↔ BYN ↔ $) с пересчётом по курсу
- 💳 Долги: кредитка, сплит, папе. Трата по кредитке растит долг, платёж — гасит.
  Показывает прогноз: при текущем темпе долг закроется к такому-то месяцу
- 🐷 Копилка: цели с прогрессом (чек-поинт 2 млн → ЭКО, 3 млн, Бразилия)
- 📋 Планы трат: лимит на категорию в месяц, «свободно до конца месяца», перерасход
- 💵 Карта Мир: комиссия $0.25 списывается с баланса автоматически
- 📊 Аналитика: круговая диаграмма, доля отложенного от дохода
- 👯 Двое сразу: у обеих всё обновляется мгновенно, записи не затирают друг друга
- 📴 Работает офлайн (кроме синхронизации)

## Как устроено

- **React + Vite**, деплой на GitHub Pages через Actions (`.github/workflows/deploy.yml`) —
  любой push в `main` автоматически выкатывает новую версию
- **Supabase** — база и вход по паролю. Данные закрыты политиками RLS: их видит
  только тот, кто вошёл и состоит в `budget_members`
- Баланс не хранится, а **считается из операций** — история и остатки не могут разойтись

### Таблицы

| Таблица | Что внутри |
|---|---|
| `budget_transactions` | операции: расход / доход / перевод / отложить |
| `budget_debts` | долги и их исходные суммы |
| `budget_goals` | цели накопления |
| `budget_limits` | планы трат по категориям на месяц |
| `budget_settings` | курсы валют, комиссия, остатки на старте |
| `budget_members` | кто имеет доступ к данным семьи |

## Разработка

```bash
npm install
npm run dev      # http://localhost:5173/budget-tracker/
npm run build
```

Ключи Supabase лежат в `src/lib/supabase.js`. Публичный ключ на то и публичный —
доступ к данным даёт не он, а вход по паролю плюс RLS.
